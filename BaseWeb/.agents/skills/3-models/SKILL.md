# BaseWeb 資料模型索引

依用途選擇檔案，開啟原始碼核對實際宣告與使用方式。

| 檔案 | 用途 |
| --- | --- |
| [Date2Dto.cs](../../../Models/Date2Dto.cs) | 描述查詢畫面的一組起訖日期輸入欄位。 |
| [XgFindTbarDto.cs](../../../Models/XgFindTbarDto.cs) | 設定查詢工具列的版面與可選操作。 |
| [XgThDto.cs](../../../Models/XgThDto.cs) | 設定表格欄標題、提示與顯示樣式。 |
| [XiBaseDto.cs](../../../Models/XiBaseDto.cs) | 定義 Xi 輸入欄位共用的標題、欄位識別、初始值與編輯狀態。 |
| [XiCheckDto.cs](../../../Models/XiCheckDto.cs) | 設定核取欄位的預設勾選狀態與標籤。 |
| [XiCheckTextDto.cs](../../../Models/XiCheckTextDto.cs) | 設定附文字輸入的核取欄位。 |
| [XiDateDto.cs](../../../Models/XiDateDto.cs) | 提供日期輸入欄位的共用配置。 |
| [XiDecDto.cs](../../../Models/XiDecDto.cs) | 設定小數輸入欄位的上下限及離開欄位時的回呼。 |
| [XiDtDto.cs](../../../Models/XiDtDto.cs) | 設定日期時間輸入欄位及分鐘選項間隔。 |
| [XiFileDto.cs](../../../Models/XiFileDto.cs) | 設定檔案上傳欄位的資料表、大小限制及允許的檔案類型。 |
| [XiHideDto.cs](../../../Models/XiHideDto.cs) | 設定隱藏欄位的識別、值與 HTML 屬性。 |
| [XiHtmlDto.cs](../../../Models/XiHtmlDto.cs) | 設定使用 Summernote 的 HTML 編輯欄位及文字長度上限。 |
| [XiIntDto.cs](../../../Models/XiIntDto.cs) | 設定整數輸入欄位的上下限及離開欄位時的回呼。 |
| [XiLinkDto.cs](../../../Models/XiLinkDto.cs) | 設定連結欄位，用於檢視或下載指定資料表的檔案。 |
| [XiRadioDto.cs](../../../Models/XiRadioDto.cs) | 設定單選欄位的選項與排列方式。 |
| [XiRadioTextDto.cs](../../../Models/XiRadioTextDto.cs) | 設定附文字輸入的單選欄位。 |
| [XiReadDto.cs](../../../Models/XiReadDto.cs) | 設定唯讀欄位的顯示格式、外框與是否儲存。 |
| [XiSelectDto.cs](../../../Models/XiSelectDto.cs) | 設定下拉式欄位的選項及是否加入空白項。 |
| [XiTextareaDto.cs](../../../Models/XiTextareaDto.cs) | 設定多行文字欄位的行數、長度、輸入樣式與回呼。 |
| [XiTextDto.cs](../../../Models/XiTextDto.cs) | 設定單行文字欄位的長度、密碼模式、輸入樣式及查找回呼。 |

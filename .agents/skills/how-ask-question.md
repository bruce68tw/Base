# 逐題收集需求

以任務提供的題目清單為準。各題可附以下規則。

- **提問條件**決定該題是否適用。條件空白或省略時，該題無額外限制。
- **問題處理規則**說明如何解讀、檢查或整理使用者的答案。
- **程式實作規則**說明確認後如何依答案實作程式。

1. 依題目清單的順序逐題檢查提問條件。跳過不適用的題目。題目依賴前一題的答案時，先取得該答案，再判斷是否提問。
2. 一次只問一題，等使用者回答後，依該題的問題處理規則檢查答案。使用者可以一次提供多題或全部答案。沿用已提供且符合規則的答案，只補問適用且缺漏或需要釐清的題目。
3. 收齊適用題目的答案後，在對話中列出需求摘要並請使用者確認。使用者若修正答案，重新檢查受影響的提問條件，補齊缺漏，再請使用者確認更新後的摘要。
4. 收到摘要確認後，依原任務的實作或執行規則繼續。

# 查找 Base 共用程式

1. 從開發需求確認需要的操作、輸入、輸出與使用情境。讀取 `../projects-intro.md`，先找相符的共用服務契約入口。PDF、字串快取、簡訊及向量資料庫操作直接進入契約索引，依用途選方法並核對原始碼。其他需求依職責選子專案，再讀取其總覽。
2. 從子專案總覽進入時，依當前需求選讀對應的 skill。

   | 需求 | Skill |
   | --- | --- |
   | 呼叫靜態工具或共用方法 | `1-static-services` |
   | 查找具體服務的建立方式或擴充點 | `2-instance-services` |
   | 選用 DTO、設定或輸入輸出資料模型 | `3-models` |
   | 沿用列舉、狀態碼或常數 | `4-enums` |
   | 呼叫共用介面或抽象基底，或查找其擴充契約 | `5-contracts` |

   如果該分類沒有索引，優先使用子專案總覽提供的專用 skill 或原始碼入口。遇到失效連結時，先核對目前工作區的模組與路徑，略過 `zz_` 前綴目錄及 `old` 目錄。
3. 開啟候選 C# 原始碼，核對命名空間、型別與方法簽章、輸入輸出、必要的初始化或 DI，以及失敗時的回傳或例外。透過 DI 使用服務時，沿用目標應用已採用的契約與注入方式。涉及註冊或實作排查時，再查目標應用的 DI 註冊與具體實作。
4. 找到相符的共用程式後優先重用，並交代選用的型別或方法及來源。找不到相符的程式時，說明已核對的候選與需求差異，再依原任務決定實作方式。

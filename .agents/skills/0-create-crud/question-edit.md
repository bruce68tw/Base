# 編輯問題

### 編輯1. 需要以下那些編輯相關功能(可多選)? 新增、修改、檢視、刪除、草稿、Copy、Word、Pdf

- **程式實作規則**　
  1. 如果有"新增"，則 View/Read tableRead 上面要放置 XgCreate，參考 DbAdm/Project。
  2. 其餘按鈕如果存在，必須在 Typescript _me.init() columns[] 建立一筆 data = '_Fun'，並在 columnDefs[] 設定 return _me.crudR.dtCrudFun() 並傳入正確參數。

### 編輯2. 除了資料主表，如果還要維護子表，請輸入子表名稱，以逗號分隔，例如: Item1, Item2。沒有子表時，請回答「無」。

- **問題處理規則**
  1. 從資料表名稱自動推斷中文名，顯示在下一題。

- **程式實作規則**　
  1. 實作資料主表時，讀取 `table-main.md`。
  2. 實作一對多子表時，讀取 `table-many.md`。
  3. 實作 URM 子表時，讀取 `table-urm.md`。
  4. 實作自訂子表時，讀取 `table-custom.md`。

### 編輯3. 請一次提供全部資料表的畫面欄位名稱清單。每張表各列一行，例如 CustMsg: CustName, Email, Phone, Created。

- **問題處理規則**
  1. 依照 `../get-field-sname.md`，查找欄位顯示名稱。
  2. 將用戶輸入的每個欄位的轉成格式: 欄位名稱-中文名-欄位種類，例如: CustName-客戶名稱-文字，做為下個題目的內容。
  3. 欄位種類清單為: 文字、數字、下拉、日期、唯讀、Check、Radio、
  4. 下拉與 Radio 欄位須在種類後附上選項來源，格式為 `XpCode-<Type>`、`Table-<Name>` 或 `自訂`。例如 `Item1-項目-下拉-XpCode-ItemType`。
  5. 欄位中文名前面加*表示必填，例如: CustName-*客戶名稱-文字
  6. 提問時列出主表及全部子表。URM 子表標示「不必填寫」，其餘資料表一次填完。
